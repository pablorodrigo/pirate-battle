# Assets and licenses

## Provenance

`assets/` is the asset pack provided with the challenge, copied unchanged from the `assets/` folder of the challenge repository. No file in it was edited, converted, optimized or added.

The pack has no license file or author credits, and its files carry no authorship metadata. It is used as the challenge provides it: as the visual base of the solution. Anyone who wants to reuse these files outside the challenge should confirm their license with the challenge authors first.

The project adds no complementary resources: no other images, sounds or fonts. Text uses the system font stack (`system-ui` and fallbacks), so no font file is bundled.

## Files the game uses

| Files | Use |
| --- | --- |
| `spritesheet/ships_miscellaneous_sheet.png` and `.xml` | Ships in three colors with their damage stages and wrecks, cannonballs, explosions and flames. |
| `tilesheet/tiles_sheet.png` and `tiles_sheet_retina.png` | Water, island sand and island decorations, at 1× and 2×. |
| `spritesheet/ui_sheet.json` | Interface metadata: sizes, nine-slice borders, content, label and fill areas, icon sizes and image paths. |
| `png/default/ui/**` and `png/retina/ui/**` | Menu panel, buttons, HUD counters, health bars, icons and the title, at 1× and 2×. |
| `ui_scene_background.png` | Background of the menus. |
| `png/default/ships/ship_1.png` | Browser tab icon. |

Files the game does not use:

- `png/*/ships`, `png/*/ship_parts`, `png/*/effects` and `png/*/tiles`: the individual files of the art that the two sheets above already contain.
- `spritesheet/ships_miscellaneous_sheet_retina.*`: it has the same size (1024 × 512) and frames as the 1× sheet, so it adds no detail.
- `spritesheet/ui_sheet_retina.json`: the 1× atlas already gives the logical sizes, and each 2× image sits at the same path under `png/retina`.
- `sounds/`: the game plays no audio yet.
- `vector/`: source files of the art.
- `preview.png`, `sample_*.png` and `logo_jungle_gaming.svg`: references for the challenge, not game assets.

## Runtime transformations

The files are used as they are; these steps happen in the browser or in the bundler and never change the files in `assets/`:

- **Ship atlas.** The sheet is described in Sparrow/Starling XML, which PixiJS does not load, so `src/game/assets/sparrowAtlas.ts` maps its frames onto textures.
- **Terrain.** Water and island tiles are drawn once per match into canvas textures, at whole-unit positions, so neighbouring texels never bleed into seams when the scene is scaled.
- **Ships and effects.** Sprites are rotated to their heading (the art faces down), scaled to their collision radius, and briefly tinted red when hit.
- **Interface.** `src/shared/ui/uiSkin.ts` turns `ui_sheet.json` into CSS custom properties: each image becomes an `image-set` of its 1× and 2× files, panels become nine-slices, and health bars clip their fill to the atlas's fill area.
- **Bundling.** Vite copies every referenced file into the build under a content-hashed name, and inlines files under 4 KB as data URLs.

## Code dependencies

The runtime libraries keep their own licenses, all MIT: React and React DOM, PixiJS, TanStack Query, Axios and MSW. `public/mockServiceWorker.js` is generated by MSW and is covered by its license. Development tools are listed in `package.json` with their licenses in their own packages.
